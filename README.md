# СКлад

Проект содержит только Windows-приложение, страницу скачивания и сервер лицензирования Full.

- `_sklad_windows_build/` — исходники, тесты, окружение сборки и последняя сборка Windows (`release-v30/SKlad.exe`).
- `downloads/SKlad.exe` — файл, который скачивается с сайта. Android появится после добавления `downloads/SKlad.apk`.
- `core/templates/downloads/`, `core/static/` — новая страница и её оформление.
- `core/desktop_licensing.py`, `core/payments.py`, `core/models.py` — покупка и проверка лицензии приложения.
- `trezo_site/`, `docker/`, `deploy/` — конфигурация запуска и размещения.

## Запуск

Рекомендуемый серверный Python: 3.12. Установить зависимости из `requirements.txt`, настроить переменные из `.env.example`, выполнить `python manage.py migrate`, `python manage.py runserver`. Django сам не загружает `.env`: переменные передаются оболочкой или Docker Compose.

Для локальной страницы без платежей: `DJANGO_DEBUG=1`, `POSTGRES_ENGINE=django.db.backends.sqlite3`, `POSTGRES_DB=local.sqlite3`. Для сервера используйте PostgreSQL, сильный `DJANGO_SECRET_KEY` и отключённый DEBUG.

Приложение запускается через `_sklad_windows_build/run.bat`, собирается через `build_exe.bat`. Сайт раздаёт отдельную копию в `downloads`.

## Очистка старого сайта

Архив в браузере, маркет, аукционы, сообщения, регистрация, админка и редактор старого сайта удалены из исходников. Старые URL ведут на главную. База пользователей и Docker-тома не удалялись. Файлы старого сайта, локальные media и старые сборки вынесены в резервную копию вне проекта:

`C:\Users\User\AppData\Local\Temp\sklad-legacy-backup-20260909-101434`

Папка содержит также `before-edit` с прежними настройками и документацией. Временную папку может очистить Windows; для долгого хранения перенесите её в надёжное место.

`.git`, настройки окружения, ключи лицензий и служебные инструкции агента сохранены. Не публикуйте `.env*` и `.desktop-license-keys`.

Публикация на сервер в рамках очистки не выполнялась. Перед обновлением старой серверной базы сделайте резервную копию и проверьте план миграций; см. `deploy/DOWNLOAD_SITE.md`.
