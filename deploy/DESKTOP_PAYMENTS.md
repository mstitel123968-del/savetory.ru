# СКлад Windows: разовая покупка 299 ₽

Приложение бесплатно хранит до 10 карточек. Бессрочная лицензия снимает только лимит количества; настройки, просмотр, редактирование и экспорт не закрываются. Архивы с более чем 10 существующими карточками не удаляются. Учётная запись сайта не требуется. Автоматических списаний нет.

## Перед включением реальных платежей

1. Установить обновлённые зависимости сайта и выполнить `python manage.py migrate` (миграция 0027).
2. Перенести секретный ключ из локального `.desktop-license-keys/private.pem` в защищённый каталог сервера **вне публичных файлов**, с доступом только сервисному пользователю. Сделать защищённую резервную копию. Не коммитить, не отправлять клиентам, не генерировать заново при обновлении. В EXE находится только соответствующий `assets/license-public.pem`.
3. Настроить `SKLAD_LICENSE_PRIVATE_KEY_FILE` на этот серверный файл. Проверить действующие `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, `YOOKASSA_RETURN_URL`, настройки чека и применимый код НДС в кабинете продавца. Тестовые платежи намеренно не активируют распространяемую версию приложения.
4. Настроить HTTPS и корректный заголовок прокси для адреса возврата. Установить лимиты запросов на `/desktop/purchase/` и `/desktop/status/` на обратном прокси: встроенный кеш-лимит действует только в пределах одного процесса, если не подключён общий кеш. Не логировать тела запросов: они содержат почту и секретный код покупки.
5. После проверки готовности включить `SKLAD_PAYMENTS_ENABLED=1` и перезапустить сайт. По умолчанию покупка выключена, приложение сообщает об этом без списаний.
6. Провести согласованную реальную проверку покупки/выдачи чека/активации и возврата до публикации установщика. В этой задаче реальные платежи не выполнялись.

## Восстановление и ограничения

До запроса серверу приложение сохраняет код покупки в `%APPDATA%\SKlad\purchase.json`. Повторные попытки используют тот же заказ и ключ идемпотентности. Для неопределённого заказа без ID платежа старше 23 часов новая попытка запрещена: требуется проверка продавцом, чтобы исключить повторное списание.

После оплаты пользователь нажимает «Проверить оплату»: сервер запрашивает YooKassa и сверяет статус, сумму, валюту, ID заказа и признак боевого платежа. Сам возврат из браузера не активирует приложение. Webhook не требуется: подтверждение происходит при проверке из приложения. Если нужен автоматический выпуск и доставка лицензии по почте без повторного открытия приложения, это отдельное расширение.

Выданная лицензия подписана Ed25519, хранится в `%APPDATA%\SKlad\license.json`, работает без сети и может быть сохранена/загружена через окно покупки. Код покупки позволяет восстановить её с сервера; его нужно хранить как пароль. Привязки к компьютеру и аккаунту нет. Бессрочную офлайн-лицензию нельзя немедленно отозвать на отключённом компьютере после возврата; абсолютной защиты от взлома локального приложения нет.

Секретные ключи и сведения YooKassa должны оставаться только на сервере. Нельзя заменять проверку лицензии флагом `paid=true` в пользовательском файле.
