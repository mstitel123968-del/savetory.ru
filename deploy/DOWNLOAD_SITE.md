# Размещение нового сайта

Страница скачивания и API `/desktop/` больше не зависят от старого архива и подписок. Проверка оплаты выполняется приложением через `/desktop/status/`; старый webhook подписок удалён.

Сборки доставляются отдельно в `downloads/` и монтируются в контейнер только для чтения. Без файла соответствующая кнопка недоступна. Приватный ключ необходимо монтировать отдельно и указать путь в `SKLAD_LICENSE_PRIVATE_KEY_FILE`; ключ не включается в Docker-образ.

## База

Новая пустая база получает только таблицу `core_desktoppurchase`. Таблица и её поля совместимы с последней версией старого проекта. Миграция `0002_ensure_license_table` создаёт таблицу, только если её ещё нет, в том числе при обновлении базы с уже отмеченной старой `core.0001_initial`.

Старые таблицы и записи миграций автоматически не удаляются. Перед обновлением существующего сервера обязательно сохранить дамп, проверить `migrate --plan`, применить миграции сначала на копии и проверить существующую лицензию. Не выполняйте откат миграций старого проекта из нового кода.

После доставки файлов: `collectstatic --clear --noinput`, перезапуск сервиса и проверка главной, скачивания и API лицензии. Nginx больше не раздаёт старые `/media/`.

Локальные проверки: 8 тестов новой страницы и лицензирования на временной базе; реальные платежи при проверке не выполняются.
