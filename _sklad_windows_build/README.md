# СКлад для Windows

Локальное настольное приложение для ведения коллекции. Аккаунт, маркет, люди, уведомления и тарифные ограничения отсутствуют.

В приложении доступны:

- темы, акцентные цвета и оформление карточек;
- выбор шрифта, масштаба и параметров типографики;
- плотность интерфейса, ширина панели, размеры карточек и отступы;
- настройка полей каждой рубрики, собственные поля и копирование наборов полей;
- до пяти изображений, статус и произвольные значения полей карточки;
- отдельный экран просмотра карточки с галереей;
- поиск, сортировка, плиточный и списочный режимы.

## Быстрый запуск

Дважды нажмите `SKlad.exe` — установка и Python не требуются.

Обновление 7 сентября: скруглённые кнопки, поля, карточки и рубрики; тонкая
прокрутка появляется только при переполнении. Логотип и иконки рубрик убраны.
Стеклянная тема включается через «Настройки → Оформление → Тема → Стеклянная».
Это локальная стилизация с градиентами и бликами, без системного преломления
или прозрачности рабочего стола. Для запуска из исходников нужен также `surfaces.py`.

Стеклянная тема использует «Цвет собственной темы» и выбранный акцент.
Просмотр карточек открывается поверх архива: миниатюры выбирают фотографию,
стрелки клавиатуры переключают изображения, Esc закрывает просмотр.

Кнопка «Экспорт» в верхней панели сохраняет текущий список (с учётом рубрики
и поиска) либо весь архив. PDF содержит изображения и поля карточек, Excel
(.xlsx) — таблицу всех полей и пути к изображениям. Экспорт работает локально.

## Бесплатная и полная версия

Бесплатно можно хранить до 10 карточек одновременно. Удаление карточки освобождает место.
Полная версия стоит 299 ₽ один раз: без подписки, срока окончания и лимита карточек.
Оформление, рубрики, просмотр, редактирование и экспорт доступны в обеих версиях.

Откройте «Настройки → Лицензия» или нажмите «Купить» рядом со счётчиком
«Заполнено N из 10» в верхней панели бесплатной версии. Укажите почту для чека
и нажмите «Купить за 299 ₽». Оплата открывается на защищённой странице ЮKassa
в браузере. Вернитесь в приложение и нажмите «Проверить оплату».
Сохраните код покупки и файл лицензии: они нужны для восстановления после переустановки.
После активации интернет для работы не требуется. Регистрация на сайте не нужна.

Для владельца: серверная часть должна быть установлена и включена по инструкции
`deploy/DESKTOP_PAYMENTS.md` в папке сайта. До этого реальные платежи недоступны.

## Запуск из исходников

Дважды нажмите `run.bat`. Требуется Python 3.11+ и зависимости из `requirements.txt`.

Горячие клавиши:

- `Ctrl+F` — поиск;
- `Ctrl+N` — новая карточка;
- нажатие по изображению или названию — просмотр карточки;
- правый щелчок по рубрике — настройка её полей.

Данные сохраняются в `%APPDATA%\SKlad`. Выбранные изображения копируются туда, поэтому исходные файлы можно перемещать.

## Сборка EXE

Запустите `build_exe.bat`. Готовый файл появится в `release\SKlad.exe`.
